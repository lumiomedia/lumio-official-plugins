# Kanaler / Channels

Personliga linjära TV-kanaler av ditt bibliotek, din watchlist och ditt debrid-moln.
Varje kanal är en uppsättning regler (genre, årtionde, längd, ordning, sändningstid);
tablån räknas fram ur väggklockan, så den rullar vidare även när du inte tittar.

- Källor: bibliotek, watchlist, debrid.
- Ingångar: huvudmenyn, startsidans rad "Sänds nu på dina kanaler" och inställningar.
- Kräver Lumio >= 0.1.625.
