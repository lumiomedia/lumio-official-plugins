# Changelog

## 0.1.2

- Continue watching: titles paused in other apps (the service's paused positions) now show in Lumio's Continue watching. Needs Lumio 0.1.636 or later.

## 0.1.1

- A large watch history or watchlist syncs in one go instead of title by title, so the first sync no longer stalls Lumio on TV boxes.

## 0.1.0

- Connect with a device code (QR on TV) — no API key needed.
- Scrobble, two-way sync of watched titles and watchlist, and MDBList lists as home rows.
