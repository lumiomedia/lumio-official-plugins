# SIMKL

Gör SIMKL till Lumios tracker, bredvid eller i stället för Trakt — filmer,
serier och anime.

- Scrobblar uppspelning (start, paus, stopp).
- Synkar sedda titlar och watchlist åt båda hållen.
- Visar dina SIMKL-statuslistor (Tittar på, Planerar att se …) och
  "Trendande på Simkl" som rader på startsidan.

Anslut med "Anslut med SIMKL": en kod och en QR-kod visas, och du godkänner
på simkl.com från telefonen eller datorn — likadant på TV:n. Varje enhet
ansluter för sig. Ingen nyckel behövs.
